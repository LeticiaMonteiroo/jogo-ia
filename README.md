## 🎯 Sobre o Projeto

Este projeto é um jogo mobile educacional (protótipo) desenvolvido com o objetivo de **conscientizar e ensinar conceitos fundamentais de Inteligência Artificial (IA)** para estudantes do ensino médio.

De forma lúdica e interativa, o jogo busca desmistificar a IA, abordando não apenas os aspectos técnicos de forma simplificada, mas também os **impactos éticos e sociais** que essa tecnologia traz para o nosso cotidiano.
